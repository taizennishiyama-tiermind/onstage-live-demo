# Project Skills

Custom skills are installed in `.claude/skills/`. Each skill has a SKILL.md with detailed instructions.

## Available Skills

### ui-ux-pro-max (`/ui-ux-pro-max`)
- **When**: UI/UX design, building pages, choosing colors/typography/styles, reviewing UI code
- **Usage**: Always run `--design-system` first, then supplement with domain/stack searches

### vercel-react-best-practices (`/vercel-react-best-practices`)
- **When**: Writing, reviewing, or refactoring React/Next.js code
- **Rules**: `.claude/skills/vercel-react-best-practices/rules/`

### pptx (`/pptx`)
- **When**: Any task involving .pptx files - creating, reading, editing, or converting presentations

### find-skills (`/find-skills`)
- **When**: User asks "how do I do X", "find a skill for X", or wants to extend capabilities
